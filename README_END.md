# Flight_delay_clustering
A data analytics pet project based on the bachelor's thesis “Comparative Analysis of Python and R for Building Intelligent Analytical Systems in Civil Aviation.”

# Objective
The goal of the practical part is to automatically divide flights into groups based on their delay profiles while simultaneously comparing Python and R as tools for building an analytical system.  
The business purpose is to identify typical profiles of problematic flights, support delay-cause analysis, and evaluate which technology stack is better suited for exploratory analytics and which is more appropriate for production use.

# Tech Stack
Python: pandas, NumPy, scikit-learn, MiniSom, UMAP, matplotlib  
R: dplyr, ggplot2, kohonen, randomForest, e1071, clusterCrit, umap

# What This Project Demonstrates
- Data preprocessing and cleaning  
- Working with a real-world open aviation dataset from BTS  
- Encoding categorical features and data standardization  
- Clustering and anomaly detection using three experimental approaches  
- Clustering quality evaluation using Silhouette Score, Davies–Bouldin Index, and Calinski–Harabasz Index  
- UMAP visualization of multidimensional data  
- Comparison of Python and R in terms of execution time and memory consumption  
- Organization of a reproducible data analytics project  

# Data
The data source is the Bureau of Transportation Statistics (BTS), Airline On-Time Performance dataset. The project uses 10 features:  
`DEP_DELAY`, `CRS_ELAPSED_TIME`, `DISTANCE`, `DAY_OF_WEEK`, `CARRIER_DELAY`, `WEATHER_DELAY`, `LATE_AIRCRAFT_DELAY`, `NAS_DELAY`, `OP_UNIQUE_CARRIER`, `ORIGIN`.  
The source CSV file can be found in: `data/BTS.csv`

# Results Interpretation
In the thesis experiments, R demonstrated stronger performance in exploratory segmentation and statistical analysis, while Python showed advantages in versatility, scalability, and integration capabilities.For a large-scale analytical solution, a combined approach may be effective: R can be used for research-oriented analysis and statistical experimentation, while Python can be used for production deployment, integration, and scalable data processing.
