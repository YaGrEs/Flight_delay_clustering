# Flight_delay_clustering
Pet-проект по аналитике данных на основе дипломной работы "Сравнительный анализ языков Python и R в построении интеллектуальных аналитических систем для гражданской авиации"

# Задача
Цель практической части - автоматически разделять рейсы на группы по профилю задержек и одновременно сравнивать Python и R как инструменты построения аналитической системы.

Бизнес-смысл - выявлять типовые профили проблемных рейсов, поддерживать анализ причин задержек и оценивать, какой набор иструментов лучше подходит для исследовательской аналитики и для промышленной эксплуатации.

# Стек
Python: pandas, NumPy, scikit-learn, MiniSom, UMAP, matplotlib  
R: dplyr, ggplot2, kohonen, randomForest, e1071, clusterCrit, umap

# Что демонстрирует проект
- Подготовку и очистку табличных данных
- Работу с реальным открытым авиационным датасетом BTS
- Кодирование категориальных признаков и стандартизацию
- Кластеризацию / выявление аномалий тремя экспериментальными подходами
- Оценку качества кластеризации через Silhouette, Davies–Bouldin и Calinski–Harabasz
- UMAP-визуализацию многомерных данных
- Сравнение скорости и потребления памяти Python и R
- Оформление воспроизводимого аналитического проекта

# Данные
Источник - Bureau of Transportation Statistics (BTS). Airline On-Time Performance. В данной работе используются 10 признаков:  
`DEP_DELAY`, `CRS_ELAPSED_TIME`, `DISTANCE`, `DAY_OF_WEEK`, `CARRIER_DELAY`, `WEATHER_DELAY`, `LATE_AIRCRAFT_DELAY`, `NAS_DELAY`, `OP_UNIQUE_CARRIER`, `ORIGIN`.  

Исходный CSV можно найти в `data/BTS.csv`

# Интерпретация результатов
В ВКР R показал сильную сторону в исследовательской сегментации и статистическом анализе, а Python - в универсальности, масштабируемости и интеграции. Для крупного аналитического решения лучшим вариантом может быть комбинированный подход, где исследование и статистические эксперименты отдаются R, а промышленная эксплуатация и интеграция - Pythonу.
